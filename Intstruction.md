# Docker Hub instruction [`unlie9/todoapp`](https://hub.docker.com/repository/docker/unlie9/todoapp/general)


## 1. Login Docker Hub

```bash
docker login
```

## 2. Pull todoapp:2.0.0 image from Docker Hub

```bash
docker pull unlie9/todoapp:2.0.0
```

## 3. Pull mysql-local image from Docker Hub

```bash
docker pull unlie9/mysql-local
```
